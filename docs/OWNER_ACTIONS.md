# Owner Actions

Nothing here blocks local development.

Before a trusted public beta:

- [ ] Choose individual or organization publisher identity.
- [ ] Select the final bundle identifier.
- [ ] Enroll in the Apple Developer Program if Developer ID distribution is approved.
- [ ] Create and protect signing and notarization credentials.
- [ ] Approve the first public GitHub Release and update-feed activation.

Codex may prepare instructions and automation for these actions, but must not accept agreements, purchase memberships, expose credentials, or publish without explicit authorization.
